# 把行動接上固定線索：動機退了以後，怎麼讓新習慣留下來

下定決心開始上健身房、寫作或經營副業，前幾天充滿幹勁，兩到四週後又回到原本的生活。如果你熟悉這種拚一陣、鬆掉、再拚一陣的循環，問題可能出在把力氣都押在動機上。

動機很適合讓人開始。要每天持續，需要另一樣東西：一個把行動接上固定線索的小系統。這篇文章陪你用四個步驟搭出這個系統，再用一週測試它有沒有在運作。

## 為什麼一股熱情撐不過一個月

用火箭來想會清楚一些。火箭起飛和加速時燒掉大量燃料，進入軌道後靠滑行前進。改變也有兩個階段：強烈的動機像起飛的燃料，幫你跨過開始的門檻；之後靠習慣、例行程序和系統維持，等行為變成自己的一部分，需要的燃料會少很多。

把這兩個階段混在一起時，常會出現下面幾種情況。

- **把起步的力量當成會一直在的力量。** 整個計畫建立在「現在很有幹勁」上，幹勁退了，計畫也跟著停。分手後開始健身、受不了沒錢而拚副業，靠的都是一次事件帶來的衝勁。
- **把及格線訂在狀態最好的那一天。** 每次都要求自己做得完整、做得漂亮，狀態差的日子乾脆不做。例如把「一次很棒的訓練」當成上健身房的標準。
- **等心情或靈感來了才開始。** 行動沒有固定的起點，做不做取決於當天的感覺。例如只在有靈感時寫作。

## 趁動機還在，搭好環境、訊號、行為、獎勵四段循環

動機還在的時候，很值得拿它來建系統。這個系統有四段：環境、訊號、行為、獎勵，對應常見的「線索、反應、獎勵」習慣迴路。設計時可以抓一個方向：讓成功容易到，沒做到反而會覺得有點好笑。

### 讓想做的事變成最省力的選擇

先看看想做的事從開始到完成要經過幾個步驟，不想做的事又有多容易做到。替想做的事拿掉阻礙，替不想做的事加上阻礙，選擇可能會慢慢往想要的方向偏。

- 健身：前一晚把運動服準備好；清掉櫥櫃裡的垃圾食物，換成能達到熱量和營養素目標的食物；先看過明天要練的動作，進健身房時心裡有清楚的計畫，也多一點期待。
- 寫作：把收集想法的 App 放在手機捷徑，寫作或排程 App 保持開著；把最重要、最難的工作排在早上。

### 替行動找一個每天固定出現的線索

找一件每天都會發生、時間固定的事，把行動接在它後面。寫好後問自己：這個線索每天都會出現嗎？它出現時，我知道下一步要做什麼嗎？

- 健身：每天同一時間出發，例如上午 11 點左右；剛開始時設鬧鐘，選一個只代表「去健身」的鈴聲。
- 寫作：早上坐到桌前喝第一杯咖啡，或開始寫作時固定播某首歌。

靈感來的時候當然可以寫，但只靠靈感當線索，行動會跟著靈感時有時無。

### 把每天的及格線降到最小版本

選一個小到幾乎不會做不到、做完又看得出確實做了的版本，當作每天的及格線，做得更多都算額外的。

- 健身：走進健身房，只答應自己做一組高強度的訓練。人已經到了，很可能會想繼續練下去。
- 寫作：一天一則貼文、一週一封電子報，品質達到最低標準，重點是發出去，不用追求完美。

### 做完立刻給自己一點好處

選一件真的會期待的小事，放在行動後面，每次做完都給，直到行動本身變成享受。

- 健身：練完去果汁店或加油站買一杯高蛋白飲。
- 寫作：完成早上兩三件主要工作後出門散步，散完步再吃早餐。

有人會說蛋白粉、代糖不夠健康。判斷獎勵合不合適時，拿它跟改變前的習慣比，會比拿它跟理想的飲食比更實際。

### 讓每天接收的資訊跟著目標走

四段循環處理的是你做出來的行動，每天看到、聽到的東西也在影響下一次的決定。接收的資訊塑造你怎麼看處境、怎麼做決定，做出的行動又決定你接下來會接觸到什麼，兩邊會互相累積。

- 追蹤兩三個跟目標有關、兼具激勵和教學的來源，取消追蹤讓你降低標準或浪費注意力的內容。以健身來說，可以取消追蹤販賣不安全感、鼓吹接受平庸的內容。
- 身邊至少有一位已經在做這件事的人，他的「正常」會慢慢變成你的正常。以寫作來說，可以在同類創作者的影片留言區回覆同路人，交換帳號後私訊，建立一群做同樣事的網路朋友。
- 檢視自己對這件事的信念，例如對身體能力的想法、覺得賺錢難不難。其中不少信念，可能在你有能力判斷之前就已經形成。

### 什麼時候這套方法還不夠

- **完全沒有起步的力量時。** 系統要靠一開始的衝勁搭起來，少了它，連拿起手機一路滑下去這種習慣都很難改。起步的力量可以來自強烈的激勵，也可以來自對現狀的強烈不滿。
- **選了自己承受不起後果的起步方式時。** 有一種做法是刻意製造壓力，例如搬進付不起的公寓，逼自己讓收入跟上。分享這個做法的人說它極端、不適合所有人，也說他其實不會無家可歸，只是當時相信會。手上沒有退路的人照做，面對的可能是真的付不出房租。選起步方式之前，先確認最壞的結果自己承擔得起。

## 用一週測試你的四段循環

### 寫下你的四段循環

1. 選一個想持續的行動。
2. 寫下四段：環境要準備和移除什麼、每天固定的線索是什麼、最小版本是什麼、做完立刻得到什麼。
3. 對照四個問題檢查：
   - 想做的事比不想做的事更省力嗎？
   - 線索每天固定出現嗎？
   - 最小版本小到做不到會覺得好笑嗎？
   - 獎勵緊接在行動之後嗎？

四個問題都答得出「是」，這一步就完成了。

### 連續七天執行並記錄

每天記三件事：線索有沒有出現、有沒有完成最小版本、獎勵有沒有給。沒做到的那天，多寫一句卡在哪裡。

### 依卡住的位置調整

| 卡住的情況 | 可能要調整的段落 |
| --- | --- |
| 忘了要做 | 訊號 |
| 想到了，但覺得麻煩 | 環境 |
| 一想到要做的份量就不想開始 | 行為 |
| 做了幾天覺得沒意思 | 獎勵，或每天接收的資訊 |

一次只改一段，下一週再測，比較容易看出是哪個調整有用。

### 怎樣算循環開始運作

七天裡，多數日子在線索出現後開始做最小版本，不必先等到有心情，循環已經開始運作了。沒做到的日子，能說出卡在哪一段，也是進展，因為你知道下週要改哪裡。

### 測試的限制

- 七天的紀錄適合看循環能不能啟動；想知道能維持多久，需要更長時間的觀察。
- 獎勵什麼時候可以拿掉，可以觀察某天沒有獎勵時，你還想不想做。
- 最小版本可能讓你做得更多，也可能一直停在最小版本；兩種情況都記下來，再決定要不要調高及格線。

## 動機負責點火，系統負責每一天

動機適合讓你開始。要每天持續，靠的是把行動接上固定線索，再用環境、最小版本和獎勵讓它容易發生。狀態差的日子也有一個做得到的版本，系統比較撐得過動機退去的那幾週。

這套做法可以用在需要每天重複的行動，例如運動、寫作、經營副業。

還有幾個問題值得接著想：循環要運作多久才會變成自動的？獎勵什麼時候可以拿掉？每天接收的資訊要怎麼持續維護，才不會被舊習慣拉回去？

# 寫作過程

## 文章選題分析

### 角度一：把行動接上固定線索

| 項目 | 內容 |
| --- | --- |
| 文章標題 | 把行動接上固定線索：動機退了以後，怎麼讓新習慣留下來 |
| 目標讀者 | 反覆開始又放棄健身、寫作或副業這類目標的人 |
| 核心問題 | 動機退了以後，怎麼讓行動每天持續？ |
| 閱讀價值 | 得到一套四段的設計步驟、一週的測試方法，以及卡住時要調整哪一段的依據 |
| 可使用的課程知識 | A 的學習成果 1、3；B 的啟動燃料與持續系統、四段循環與兩個範例的對照表、調整輸入；C 的實作題「為一個目標寫出四段循環」；D 的文章主題「把行動接上固定線索」 |
| 可以實作或驗證的內容 | 寫下四段並用四個問題檢查；連續七天執行並記錄；依卡住的位置調整 |

### 角度二：如何判讀成功經驗的適用範圍

| 項目 | 內容 |
| --- | --- |
| 文章標題 | 別人說有效的方法，對你有效嗎？判讀成功經驗的適用範圍 |
| 目標讀者 | 常看到別人分享成功方法、想判斷能不能照做的人 |
| 核心問題 | 一個人多次成功的經驗，能支持到什麼程度？ |
| 閱讀價值 | 判讀個人經驗時有一組可以檢查的條件 |
| 可使用的課程知識 | B 的戰術性壓力與其限制；C 的應用題「寫下壓力成真時實際會失去什麼」；D 的「戰術性壓力的效果只有個人經驗支持」與文章主題「如何判讀成功經驗的適用範圍」 |
| 可以實作或驗證的內容 | 拿一個別人分享的方法，列出它成立需要的條件與自己是否具備；但材料只有一個個案，判讀方法大多要延伸 |

### 推薦理由

- 角度一有健身與寫作事業兩組對應四段的具體做法，材料支撐最多；角度二只有戰術性壓力一個個案。
- 角度一的驗證讀者一週內就能自己做；角度二的判讀條件幾乎都要靠延伸分析建立。
- 一般課程摘要會列出四段與範例；這篇把四段寫成換成任何目標都能用的檢查問題，再加上七天測試與依卡住位置調整的方法。
- 角度二的重點保留在文章「什麼時候這套方法還不夠」，讓讀者知道起步方式要承擔得起。

## 思考架構

| 通用模式 | 材料裡的實例 | 換成其他資料時要找的 |
| --- | --- | --- |
| 起步的力量與持續的系統分屬兩個階段 | 火箭起飛燒大量燃料、進入軌道後滑行；分手後開始健身、受不了沒錢而拚副業 | 這次改變靠什麼起步，又打算靠什麼維持 |
| 誤解：把起步的力量當成會一直在 | 動機退了，停掉健身、擱下事業 | 計畫的哪些部分依賴「現在很有幹勁」 |
| 誤解：把及格線訂在狀態最好的那一天 | 成功是走進健身房，不要求一次很棒的訓練 | 目前的每日標準，在狀態差的日子做不做得到 |
| 誤解：等心情或靈感來了才開始 | 不只靠靈感當寫作的訊號 | 行動目前由什麼觸發 |
| 環境：拿掉想做的事的阻礙，加上不想做的事的阻礙 | 前一晚備好衣服、清掉垃圾食物、先研究明天的動作；想法收集 App 放捷徑、困難工作排早上 | 目標行動前後的步驟與阻礙 |
| 訊號：每天固定出現的線索 | 上午 11 點左右、專屬鈴聲的鬧鐘；第一杯咖啡、固定的一首歌 | 每天固定發生的事件 |
| 行為：小到做得到、又看得出做了的最小版本 | 一組高強度訓練；一天一則貼文、一週一封電子報 | 這個行動能縮到多小仍算做了 |
| 獎勵：緊接在行為之後的享受 | 高蛋白飲；散步後再吃早餐；比較對象是改變前的習慣 | 自己真的會期待的小事 |
| 輸入跟著目標走 | 追蹤兩三個來源、取消追蹤販賣不安全感的內容、身邊有一位在訓練的人、留言區結識同路人、檢視信念 | 跟目標有關的來源、人與信念 |
| 起步方式要承擔得起 | 戰術性壓力：搬進付不起的公寓；相信會無家可歸、實際不會；極端、不適合所有人 | 這個起步方式最壞的結果是什麼 |
| 一週測試與依卡住位置調整 | 材料沒有對應實例 | 每天的紀錄、卡住的位置 |

## 內容來源區分

- **課程有證據支持的知識**：啟動燃料與持續系統兩階段及火箭比喻；分手後健身、受不了沒錢拚副業兩個起步例子；環境、訊號、行為、獎勵四段的定義，以及健身與寫作事業的具體做法，包括上午 11 點、專屬鈴聲、一組高強度訓練、一天一則貼文、一週一封電子報、高蛋白飲、散步後再吃早餐；判斷獎勵時與改變前的習慣比較；不只靠靈感當訊號；少了起步燃料連滑手機的習慣都難改；輸入與輸出互相影響；追蹤來源、身邊的人、檢視信念的做法；戰術性壓力極端、不適合所有人，以及相信會無家可歸、實際不會的差別。
- **AI 延伸分析**：開場的讀者情境；把兩階段混在一起時的三種誤解，其中第二、三種由最小版本與訊號推導而來；各段開頭的通用寫法與檢查問題；「選擇可能會慢慢往想要的方向偏」；沒有退路的人照做可能真的付不出房租；一週測試、每日紀錄、卡住位置與段落的對應表、一次只改一段、成功標準；用「沒有獎勵時還想不想做」觀察獎勵能否拿掉；最小版本兩種結果的處理；可套用的情境。
- **尚待驗證的內容**：四段循環與「線索、反應、獎勵」習慣迴路研究的對應，材料把它歸到操作制約，並說經《The Power of Habit》與《Atomic Habits》普及，沒有附出處；最小版本是否真的讓人繼續做下去；戰術性壓力的效果只有個人經驗；循環要多久才會自動化；獎勵何時可以拿掉。

## 待補充項目

1. 待實作：「用一週測試你的四段循環」還沒有人執行過，完成後可把真實紀錄補進文章。
2. 待驗證：查證習慣迴路的原始研究，確認四段中哪些有實證支持。
3. 待驗證：最小版本能否提高持續率，需要找研究或自行長期記錄。
4. 待補充：本次「我的實作經驗或想法」為（無），文章不寫個人經驗；有真實經驗時可替換開場情境。
