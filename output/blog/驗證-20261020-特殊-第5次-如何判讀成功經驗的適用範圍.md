# 「這招對我最有效」能借多少？用四個問題判讀一段成功經驗

有人分享經驗時說：「這個做法我用過很多次，我覺得它是最好的方法。」說話的人看起來確實成功了，這句話也很有說服力。跟著做之前，可以先花幾分鐘把這段話拆開：當事人當時面對的是什麼、他說的「有效」靠什麼支撐、他自己又劃了哪些界線。

這篇用一個很極端的例子示範拆法。拆完之後，你可以拿同一組問題去讀其他人的成功經驗。

## 一段成功經驗容易被讀過頭的四個地方

讀別人的成功經驗時，有四個地方特別容易讀得比原話更多：

- **把當時相信的後果，當成實際後果。** 經驗分享裡描述的後果，可能是當事人當時的感受。讀者容易把它記成當事人真的承擔了這個後果。
- **把重複使用，當成反覆有效。** 「我做過很多次」說明當事人一再選擇這個做法；每一次結果如何，要另外看。
- **把個人排名，當成比較結果。** 「最好」「最有效」需要和其他做法比過才成立。依據只有當事人的感受時，它是一個人的排名。
- **把當事人自己說的限制，輕輕帶過。** 「這不適合每個人」這類提醒如果夾在鼓舞的話中間，很容易被略過。

來看一個例子。有位經營自己事業的人，把他用過的一種方法叫做「戰術性壓力」：搬進一間付不起的公寓，逼自己把事業做到付得起房租，否則他相信自己會無家可歸。他說這份相信給了他把事情做成的動力，這種做法他用過很多次，他個人認為這是最好的事業或財務成長技巧。

同一段話裡，他也說了另外幾件事：他當然不會真的無家可歸，無家可歸是他當時相信的後果；這個做法聽起來很極端，因為它確實極端；它不是每個人都適合。

只記住前半段，很容易把它讀成「押上住處逼自己成功，是最好的成長方法」。四個容易讀過頭的地方，在這段話裡都找得到。

## 用四個問題拆開一段經驗

讀到想借用的成功經驗時，可以依序問自己：

1. 當事人當時相信會發生什麼？實際上會發生什麼？
2. 他說的「有效」，依據是次數、感受，還是和其他做法的比較？
3. 他自己說了哪些限制？
4. 換成我，實際要承擔的後果是什麼？

拿戰術性壓力的例子來試：

| 問題 | 這段經驗裡找得到的內容 |
| --- | --- |
| 當時相信與實際的後果 | 當時相信付不出房租會無家可歸；他也說自己當然不會無家可歸 |
| 「有效」的依據 | 用過很多次、個人認為是最好的技巧；沒有各次的結果，也沒有和其他做法比較 |
| 當事人說的限制 | 聽起來極端，因為確實極端；不是每個人都適合 |
| 換成我的實際後果 | 要由讀者自己填 |

拆完可以看到，推動他的是一個他自己說不會發生的後果，「最好」目前是他個人的評價。這段經驗能支持「有人多次用過這個方法，他自認有效」。要說它比其他方法有效，或換一個人也會成功，這段話裡還找不到依據。

第四題值得多停一下。他說自己不會無家可歸，卻沒有說靠什麼避開最壞的結果。如果你付不出房租時真的可能失去住處，你的處境和他自述的不同，這段經驗沒有涵蓋你。

這四個問題只用到經驗分享本身的話，讀的當下就能做。它們用來判斷一段話能支持多少結論；想知道方法本身有沒有效，仍需要各次結果，以及和其他做法的比較。分享裡如果附了這些資料，第二題的答案會跟著改變，能借用的範圍也可能變大。

## 把判讀寫成四欄表，檢查自己有沒有讀過頭

想確認自己是不是把一段經驗讀得太滿，可以把判讀寫下來：

1. 選一段你最近讀到、想跟著做的成功經驗。
2. 畫四欄：當時相信的後果、實際後果、「有效」的依據、當事人說的限制。
3. 每一格只填能指回原話的內容；找不到原話的格子寫「未知」。
4. 寫完後，把你原本對這段經驗的印象寫成一兩句話，例如「這方法很有效」「我應該也適合」，再逐句看表裡有沒有原話撐得住。

用戰術性壓力的例子填這張表，「實際後果」可以填「他說不會無家可歸」，他靠什麼確定這一點只能寫「未知」；「有效的依據」可以填「用過很多次」「個人認為最好」，各次結果和比較結果都寫「未知」。

做完這張表，可以觀察兩件事：哪些格子是「未知」，以及你原本的印象裡，有沒有找不到原話支撐的句子。每一格都指得回原話，你也能分別說出「這段經驗能支持什麼」和「還缺哪些依據」，這一步就完成了。

有些分享完全沒有交代實際後果或限制，表裡可能出現好幾格「未知」。這時能借用的部分可能很少，比較穩妥的做法是先把它當成一種說法，等找到更多資料再決定。另外，這張表整理的是證據程度；適不適合你，還要回到第四題，把你自己的實際後果放進來一起看。

## 讀下一段成功經驗前，可以帶走的判讀習慣

- 把當事人當時相信的後果，和實際會發生的後果分開。
- 把使用次數、個人感受和比較結果分開看，只有前兩者時，結論停在當事人自評。
- 把當事人自己說的限制，當成借用前要先回答的條件。

這組問題可以試著用在其他個人經驗分享上，例如有人說某種工作方法或學習方法「對我最有效」。遇到填不出來的格子，先記成「未知」，等找到原話或資料再補。

戰術性壓力的例子還留著兩個問題：他靠什麼確定自己不會無家可歸，以及「不是每個人都適合」指的是哪些人。他在限制之後只補了一句「相信自己的人看到這裡會點頭」，把認同這個方法和有自信連在一起，沒有說出可以檢查的條件。在這些答案出現之前，這段經驗能借用的範圍，停在「有人這樣做過，他自認有效」。

### 推薦理由

選角度一。材料只有一段個人自述，最充分的證據是他說了什麼，以及這些話能支持到哪裡；角度一的內容是判讀這些話，每個步驟都能指回原話，讀者也能用四欄表自行驗證。角度二要評估壓力的效果與適用者，材料沒有比較資料、各次結果或適用條件，寫下去容易用推論補滿，也可能被讀成建議讀者承擔付不起的支出。

一般課程摘要會重述「有人用付不起的公寓逼自己成功」；這篇把這段經驗當成示範材料，教讀者拆開相信與實際、次數與比較、主張與限制，再把同一組問題用到別的經驗分享上。
