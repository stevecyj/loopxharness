# Workflow

每次換課程只改這份檔案；`prompts/` 裡的提示詞保持不動。

## 把學習成果轉成 blog

| 欄位                       | 值                                                  |
| -------------------------- | --------------------------------------------------- |
| 提示詞                     | `prompts/blog/把學習成果轉成blog.md`                     |
| Prompt 1：進階學習筆記     | `output/預期學習成果/網頁開發者的 AI 入門.md`                    |
| 原始課程筆記／逐字稿       | `課程材料/introduction to ai for web developers.md` |
| 我的實作經驗或想法         | （無）                                              |
| 輸出位置                   | `output/blog/<依文章內容取的繁中檔名>.md`           |

執行方式：先讀取並遵守 `docs/project-constitution.md`，再讀取「提示詞」及其引用的 Standard Card，以上表的進階學習筆記、原始課程筆記／逐字稿、我的實作經驗或想法作為輸入材料，依提示詞及專案憲法決定是否寫入「輸出位置」。標示（無）的欄位視為未提供。`<依文章內容取的繁中檔名>`
是佔位符，執行時代換成實際檔名：用繁體中文簡短概括這篇文章的主題，不同課程會產生不同檔名。
