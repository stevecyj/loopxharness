# Workflow

每次換課程只改這份檔案；`prompts/` 裡的提示詞保持不動。

## 從課程內容重建學習成果

| 欄位     | 值                                                  |
| -------- | --------------------------------------------------- |
| 提示詞   | `prompts/從課程內容重建學習成果.md`                 |
| 課程名稱 | Introduction to AI for Web Developers               |
| 課程筆記 | （無）                                              |
| 逐字稿   | `課程材料/introduction to ai for web developers.md` |
| 輸出位置 | `output/<依課程內容取的繁中檔名>.md`                |

執行方式：讀取「提示詞」，以上表的課程名稱、課程筆記、逐字稿作為課程材料，結果寫入「輸出位置」。`<依課程內容取的繁中檔名>`
是佔位符，執行時代換成實際檔名：用繁體中文簡短概括這門課的主題（例如「網頁開發者的 AI 入門」），不同課程會產生不同檔名。
