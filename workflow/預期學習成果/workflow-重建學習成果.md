# Workflow：從課程內容重建學習成果

新增或更換課程時，直接把材料放進 `課程材料/` 即可，不必手動修改本檔的檔名；產出對應表由 Agent 執行後自動維護。

## 固定設定

| 欄位     | 值                                                  |
| -------- | --------------------------------------------------- |
| 提示詞   | `prompts/預期學習成果/從課程內容重建學習成果.md`    |
| 材料目錄 | `課程材料/`（每個檔案代表一份獨立材料）             |
| 輸出位置 | `output/預期學習成果/<依課程內容取的繁中檔名>.md`   |

## 產出對應表

| 課程材料（逐字稿）                                   | 課程名稱                              | 學習成果輸出路徑                                                            |
| ---------------------------------------------------- | ------------------------------------- | --------------------------------------------------------------------------- |
| `課程材料/introduction to ai for web developers.md` | Introduction to AI for Web Developers | `output/預期學習成果/網頁開發者的 AI 入門.md`                               |
| `課程材料/從動機到持續行動-使用者提供逐字稿.md`      | 從動機到持續行動                      | `output/預期學習成果/驗證-20261020-正常-第5次-從動機到持續行動.md`          |
| `課程材料/驗證-戰術性壓力-原文節錄.md`               | 戰術性壓力（原文節錄）                | `output/預期學習成果/驗證-20261020-特殊-第5次-戰術性壓力的限制.md`          |
| `課程材料/ViteConf 2026.md`                          | ViteConf 2026                         | `output/預期學習成果/ViteConf 2026：AI 代理時代的前端工具鏈與生態系演進.md` |
| `課程材料/想成功，得有點不切實際.md`                 | 想成功，得有點不切實際                | `output/預期學習成果/用不切實際的目標重塑注意力與行動.md`                   |

## 執行方式

1. 先對照上方「產出對應表」，並用檔案清單工具列出 `課程材料/` 與 `output/預期學習成果/` 的檔名（此階段只比對檔名，**不要讀取 `課程材料/` 的檔案內文**，以免材料數量多或篇幅長時讓使用者空等），向使用者回報最新盤點結果並確認本次要處理的材料：
   - **已有對應輸出**：詢問使用者是否要重新執行並覆蓋，還是跳過。
   - **尚無對應輸出**：列出新材料檔名，一併請使用者確認本次是否處理。
   - **詢問額外課程筆記**：一併詢問使用者「本次除了逐字稿外，有沒有額外的課程筆記要一併提供？（預設為『無』）」。
2. 經使用者確認本次要執行的材料清單後，讀取並遵守 `docs/project-constitution.md`、本檔指定的「提示詞」與對應 Standard Card（`standard-cards/預期學習成果/從課程內容重建學習成果.md`），再只讀取本次要處理的材料內文：
   - 自動依材料內容或檔名推導課程名稱，搭配使用者提供的額外課程筆記（預設或回覆無則視為未提供），產出學習成果並通過 Standard Card 驗收後寫入 `output/預期學習成果/<依課程內容取的繁中檔名>.md`。
3. 寫入完成後，由 Agent 自動更新本檔的「產出對應表」，並同步更新 `workflow/blog/workflow-轉成blog.md` 對應表中的「Prompt 1：進階學習筆記」欄位。
