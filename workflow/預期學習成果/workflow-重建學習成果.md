# Workflow：從課程內容重建學習成果

新增或更換課程時，直接把材料放進 `課程材料/` 即可，不必手動修改本檔的檔名；產出對應表由 Agent 執行後自動維護。

## 固定設定

| 欄位     | 值                                                  |
| -------- | --------------------------------------------------- |
| 提示詞   | `prompts/預期學習成果/從課程內容重建學習成果.md`    |
| 材料目錄 | `課程材料/`（每個檔案代表一份獨立材料）             |
| 輸出位置 | `output/預期學習成果/<依課程內容取的繁中檔名>.md`   |

## 產出對應表

| 課程材料（逐字稿）                                   | 課程名稱                              | 課程筆記 | 學習成果輸出路徑                                                |
| ---------------------------------------------------- | ------------------------------------- | -------- | --------------------------------------------------------------- |
| `課程材料/introduction to ai for web developers.md` | Introduction to AI for Web Developers | （無）   | `output/預期學習成果/網頁開發者的 AI 入門.md`                   |
| `課程材料/從動機到持續行動-使用者提供逐字稿.md`      | 從動機到持續行動                      | （無）   | `output/預期學習成果/驗證-20261020-正常-第5次-從動機到持續行動.md` |
| `課程材料/驗證-戰術性壓力-原文節錄.md`               | 戰術性壓力（原文節錄）                | （無）   | `output/預期學習成果/驗證-20261020-特殊-第5次-戰術性壓力的限制.md` |

## 執行方式

1. 先讀取並遵守 `docs/project-constitution.md`，再讀取「提示詞」及其引用的 Standard Card（`standard-cards/預期學習成果/從課程內容重建學習成果.md`）。
2. 掃描 `課程材料/`（或使用者指定的材料），對照上方「產出對應表」與 `output/預期學習成果/` 內的實際檔案：
   - **尚無對應輸出**：自動依材料內容或檔名推導課程名稱（未提供課程筆記時填「（無）」），產出學習成果並通過 Standard Card 驗收後寫入 `output/預期學習成果/<依課程內容取的繁中檔名>.md`。
   - **已有對應輸出**：先向使用者確認「該材料已有對應的學習成果輸出，是否要重新跑一次流程（覆蓋既有輸出），還是跳過？」，經使用者確認重跑後才執行。
3. 寫入完成後，由 Agent 自動更新本檔的「產出對應表」，並同步更新 `workflow/blog/workflow-轉成blog.md` 對應表中的「Prompt 1：進階學習筆記」欄位。
